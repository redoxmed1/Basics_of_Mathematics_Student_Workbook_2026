### Exercise 3. When is a matrix product defined?

The dimensions are $A:2\times3$, $B:3\times4$, $C:4\times2$, and $D:2\times2$.

- $AB$: defined, with size $2\times4$.
- $BA$: not defined.
- $BC$: defined, with size $3\times2$.
- $CB$: not defined.
- $AC$: not defined.
- $CA$: defined, with size $4\times3$.
- $AD$: not defined.
- $DA$: defined, with size $2\times3$.

A product $XY$ is defined when the number of columns of $X$ equals the number of rows of $Y$.
